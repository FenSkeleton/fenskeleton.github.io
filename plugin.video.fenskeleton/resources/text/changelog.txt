v0.0.25 - Source Failover Playback
- Added shared source failover for manual selection, Autoplay, Random Next Up, and scraped Next Episode playback.
- Failed sources now advance through the existing ordered scrape results without re-scraping or looping back to earlier choices.
- Added "Auto Try Next Source on Failure" under Playback Utilities, enabled by default.
- A single "No playable streams found" message is now shown only after every eligible source has failed.

v0.0.24
- Added a native Simkl cache so Simkl Only works without a Trakt account.
- Added one-time full Simkl history/progress import followed by activities-gated incremental refreshes.
- Added Simkl watched indicators, resume points, Continue Watching data, native Next Episodes hints, and Simkl list browsing.
- Added full Simkl playback start, pause, resume, and stop scrobbling.
- Added Simkl list manager actions for Watching, Plan to Watch, On Hold, Completed, and Dropped.
- Moved Trakt-to-Simkl history migration into Tools and kept it strictly manual.
- Removed the automatic Trakt cache-to-WatchState startup import that processed the full history on every scheduled run.
- Removed repeated Trakt repair checks from every Next Episodes build and bounded legacy Trakt candidate expansion.
- Added manual Simkl refresh, rebuild, and WatchState utilities under Tools.
- Added safe playback-stop handling around Simkl progress writes.

v0.0.23
- Fixed QR code image caching so Simkl authorization displays the correct Simkl QR instead of a stale Trakt QR.
- No account changes required.
