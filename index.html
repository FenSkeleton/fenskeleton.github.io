FenSkeleton

A lightweight Kodi video add-on with the Fen-Mage skin.

Built to stay lean, fast, and easy to install.

Install Source

Add this source in Kodi:

https://fenskeleton.github.io/

Or download the repository installer directly:

Download FenSkeleton Repository

Installation Steps

  1. Open Kodi Settings.
  2. Go to File Manager and choose Add Source.
  3. Enter https://fenskeleton.github.io/ as the source.
  4. Return to Add-ons and choose Install from zip file.
  5. Open the FenSkeleton source, then browse to zips → repository.fenskeleton.
  6. Install the FenSkeleton Repository zip.
  7. Choose Install from repository.
  8. Install FenSkeleton and the Fen-Mage skin.

Important Note

FenSkeleton does not bundle external scraper packages. Configure your preferred compatible scraper package separately.
